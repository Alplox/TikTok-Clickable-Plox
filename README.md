# 📱 TikTok Clickable Plox

**TikTok Clickable Plox** es un userscript diseñado para mejorar la experiencia del usuario en TikTok Desktop al hacer que los videos relacionados sean clicables a través de las miniaturas y títulos con la rueda del raton. Además, proporciona una opción que permite a los usuarios abrir estos videos en una nueva pestaña con un clic normal.

## ✨ Características

- **Videos Relacionados Clicables:** Permite que las miniaturas y títulos de videos relacionados en TikTok sean clicables.
- **Opción de Alternancia:** Los usuarios pueden activar o desactivar la función para abrir videos siempre en una nueva pestaña con un simple clic.
- **Estilos Personalizados:** Aplica estilos CSS para asegurar que los aspectos visuales de los elementos clicables sean consistentes.

## 🛠️ Requisitos

Necesitas un gestor de scripts de usuario como:

- [Violentmonkey](https://violentmonkey.github.io/)
- [Tampermonkey](https://www.tampermonkey.net/)
- [Greasemonkey](https://www.greasespot.net/)

## 📦 Instalación

1. Instala un gestor de userscripts (ver arriba)
2. 📥 [Haz clic aquí para instalar el script](https://raw.githubusercontent.com/Alplox/TikTok-Clickable-Plox/refs/heads/main/tiktok-clickable-plox.user.js)

## Características

- Al visitar TikTok, verás que los videos relacionados (miniaturas y títulos) ahora son clicables con la rueda del raton como en cualquier otro sitio.
- Aparecerá un botón de alternancia en la parte inferior derecha de la pantalla. Haz clic en este botón para habilitar o deshabilitar la función de abrir videos relacionados en una nueva pestaña.
